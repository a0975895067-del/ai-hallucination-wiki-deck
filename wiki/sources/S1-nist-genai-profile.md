# S1｜NIST Generative AI Profile

- 類型：官方風險管理文件
- 年份：2024
- 原始來源：https://doi.org/10.6028/NIST.AI.600-1
- 用於投影片：2、4、10

## 核心主張

1. NIST 使用「confabulation」描述生成式 AI 自信呈現錯誤或虛假內容，也包含偏離輸入或前後矛盾。
2. 這類現象與生成模型依統計分布預測輸出的設計有關。
3. 風險在醫療等重要決策情境特別高，因為使用者可能相信並依錯誤內容行動。
4. 虛構的引文與看似合理的推理步驟，也可能增加不當信任。

## 限制

這是跨產業風險管理文件，不是單一模型的效能比較；不能用來宣稱某個模型的幻覺率。
